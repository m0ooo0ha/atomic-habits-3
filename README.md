# 🎯 لعبة الأسئلة الجماعية (Arabic Group Quiz)

لعبة أسئلة جماعية بسيطة تعمل مباشرة في المتصفح.

## الملفات
- `index.html`: واجهة اللعبة.
- `styles.css`: التصميم.
- `script.js`: منطق اللعبة.

## التشغيل المحلي
افتح `index.html` مباشرة، أو استخدم سيرفر محلي:

```bash
python3 -m http.server 8000
```

ثم افتح:

```text
http://127.0.0.1:8000/index.html
```

## طريقة اللعب
1. أضف لاعبين (لازم لاعبين أو أكثر).
2. اضغط **ابدأ اللعبة**.
3. كل دور يطلع سؤال للاعب الحالي.
4. الإجابة الصحيحة تعطي +1 نقطة.
5. في النهاية تظهر لوحة النتائج والفائز.

## النشر على GitHub Pages
1. ارفع المشروع إلى GitHub.
2. افتح **Settings > Pages**.
3. اختر:
   - **Source:** Deploy from a branch
   - **Branch:** main / (root)
4. احفظ وانتظر دقيقة إلى 3 دقائق.
5. رابط اللعبة بيكون غالبًا:

```text
https://USERNAME.github.io/REPO_NAME/
```

## ملاحظات
- اللعبة تدعم العربية واتجاه RTL.
- تقدر تعدل الأسئلة من `script.js` داخل مصفوفة `defaultQuestions`.
